# 需求文档

## 1. 应用概述

**应用名称**：网页待办事项小工具

**应用描述**：一款纯静态网页待办事项管理工具，支持按日期管理待办任务和长期事项，具备任务增删改查、拖拽排序、状态筛选等功能，数据存储于浏览器本地，可通过GitHub Pages部署访问。界面采用卡通蓝色系设计风格，背景为鲸鱼娘卡通图案。

**技术约束**：
- 纯静态网页，无后端依赖
- 使用原生HTML + CSS + JavaScript实现
- 文件结构：index.html（页面结构）、styles.css（样式）、app.js（逻辑）
- 可上传至GitHub并通过GitHub Pages地址访问
- 数据存储使用浏览器localStorage

## 2. 用户与使用场景

**目标用户**：需要管理日常待办事项和长期计划的个人用户

**核心使用场景**：
- 记录并管理当天或特定日期的待办任务
- 记录不绑定日期的长期事项
- 标记任务完成状态
- 调整任务优先级顺序
- 按完成状态筛选任务

## 3. 页面结构与功能说明

### 3.1 页面整体结构

```
网页待办事项小工具
├── 顶部栏
│   ├── Tab切换区（左侧）
│   └── 日期选择器（右侧）
├── 筛选器
├── 任务列表区
└── 底部添加任务区
```

### 3.2 顶部栏

**Tab切换区（左侧）**：
- 包含两个Tab：「待办」和「长期」
- 默认选中「待办」Tab
- 点击Tab切换当前视图，列表内容即时刷新
- 「待办」Tab：展示与选定日期绑定的任务
- 「长期」Tab：展示不绑定日期的长期事项

**日期选择器（右侧）**：
- 默认显示当前日期（2026年8月27日）
- 用户可选择任意日期
- 切换日期后，「待办」Tab下的任务列表即时刷新为该日期的任务
- 在「长期」Tab下，日期选择器不影响列表内容

### 3.3 筛选器

位于任务列表上方，包含三个筛选选项：
- 「全部」：显示所有任务
- 「待办」：仅显示未完成的任务
- 「已完成」：仅显示已完成的任务
- 默认选中「全部」
- 切换筛选条件后列表即时刷新

### 3.4 任务列表区

**任务条目结构**：
- 自动编号：每条任务前显示序号（1. 2. 3. ...），按当前列表顺序自动生成
- 勾选框：标记任务完成/待办状态，点击切换状态
- 任务内容：显示任务文本
- 拖拽把手：用于拖拽调整任务顺序
- 删除按钮：点击删除该任务

**交互功能**：
- 拖拽排序：用户可拖动任务条目调整顺序，拖拽结束后自动保存新顺序
- 勾选状态切换：点击勾选框切换任务完成/待办状态，状态变更实时保存
- 删除任务：点击删除按钮移除任务，数据实时保存
- 列表滚动：任务过多时列表区域自动出现滚动条（overflow-y: auto），窗口大小保持固定

### 3.5 底部添加任务区

- 固定在页面底部
- 包含输入框和「添加任务」按钮
- 用户在输入框中输入任务内容，点击按钮或按回车键添加任务
- 添加成功后输入框自动清空
- 新任务添加至当前列表末尾，数据实时保存
- 在「待办」Tab下添加的任务绑定当前选定日期
- 在「长期」Tab下添加的任务不绑定日期

## 4. 业务规则与逻辑

### 4.1 数据存储规则

- 使用浏览器localStorage存储数据
- 数据按日期和长期事项分开存储
- 存储内容包括：任务文本、完成状态、任务顺序
- 数据操作（添加、删除、拖拽排序、勾选状态变更）实时保存
- 页面刷新后数据不丢失
- localStorage按域名隔离，GitHub Pages访问时数据存储在该域名下

### 4.2 任务编号规则

- 编号根据当前列表顺序自动生成
- 拖拽排序后编号自动更新
- 筛选后编号按筛选结果重新生成

### 4.3 Tab与日期联动规则

- 切换至「待办」Tab时，列表展示当前选定日期的任务
- 切换至「长期」Tab时，列表展示所有长期事项，日期选择器不影响列表内容
- 在「待办」Tab下切换日期，列表即时刷新为新日期的任务

### 4.4 筛选规则

- 筛选条件应用于当前Tab下的任务列表
- 筛选不影响数据存储，仅影响显示
- 切换Tab或日期后，筛选条件保持不变

## 5. 设计风格要求

### 5.1 色彩与风格

- 主色调：卡通蓝色系（天蓝、水蓝、奶油白）
- 设计元素：圆角、柔和阴影、手绘风格边框和图标
- 字体：圆润字体
- 整体氛围：卡通轻松感

### 5.2 背景图设置

- 背景图文件名：bg.jpg
- 在styles.css中使用background-image引用背景图
- 背景图路径写在CSS开头并添加注释说明，方便用户替换
- 用户可将同名图片文件（bg.jpg）放置在同目录下直接替换背景
- 默认兜底方案：使用纯CSS绘制的卡通海洋/鲸鱼渐变背景，用户放置bg.jpg后自动覆盖

### 5.3 界面文字

- 所有界面文字使用中文

## 6. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 输入框为空时点击添加任务 | 不执行添加操作，可提示用户输入内容 |
| 任务列表为空 | 显示空状态提示 |
| localStorage存储失败 | 任务仍可正常显示，但刷新后数据丢失 |
| 拖拽过程中松开鼠标 | 任务停留在当前位置，保存新顺序 |
| 删除任务后列表为空 | 显示空状态提示 |
| 切换日期后该日期无任务 | 显示空状态提示 |
| 筛选后无符合条件的任务 | 显示空状态提示 |

## 7. 验收标准

1. 打开网页，默认显示「待办」Tab和当前日期（2026年8月27日），任务列表为空或显示已存储的当日任务
2. 在底部输入框输入任务内容，点击「添加任务」按钮，任务成功添加至列表末尾并自动编号
3. 勾选任务前的勾选框，任务状态切换为已完成，刷新页面后状态保持
4. 拖动任务条目调整顺序，松开后编号自动更新，刷新页面后顺序保持
5. 点击任务的删除按钮，任务从列表中移除，刷新页面后任务不再显示
6. 切换至「长期」Tab，列表展示长期事项，添加任务后任务不绑定日期
7. 在「待办」Tab下切换日期，列表即时刷新为新日期的任务
8. 使用筛选器选择「待办」或「已完成」，列表仅显示符合条件的任务
